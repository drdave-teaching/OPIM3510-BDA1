# Weeks 1–4: Python Bootcamp

From your very first line of Python to a full exploratory data analysis of **real Connecticut home sales**. Every notebook opens in Google Colab with one click and reads its data straight from this repo.

> **Weeks 1–4 are AI-free.** You can only check AI-written code if you can read code yourself, so let it come out of your fingers first: 15 minutes a day, twice a day if you can. Claude comes in Week 5.

In Colab, choose **File → Save a copy in Drive** so your changes are saved to your own copy.
